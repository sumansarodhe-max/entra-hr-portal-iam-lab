# Microsoft Entra ID IAM Lab – HR Portal

## Overview

A hands-on Microsoft Entra ID Identity and Access Management (IAM) lab simulating an HR portal environment.

This project demonstrates practical implementation of identity management, access control, enterprise applications, SSO, administration, and monitoring using Microsoft Entra ID.

## Objectives

- Create and manage users and groups
- Assign Microsoft Entra roles and permissions
- Configure an enterprise application
- Implement access control using group-based assignment
- Configure Single Sign-On (SSO)
- Explore administrative units and role assignments
- Configure and review Conditional Access
- Review audit and sign-in activity
- Understand SCIM provisioning concepts and limitations

## Technologies Used

- Microsoft Entra ID
- Microsoft Azure
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Conditional Access
- Enterprise Applications
- Single Sign-On (SSO)
- Audit Logs
- SCIM Provisioning

## Lab Implementation

### 1. User Management

- Created sample users
- Managed user properties
- Reviewed user accounts and directory information

### 2. Group Management

- Created the IT team group
- Added users as group members
- Demonstrated group-based access management

### 3. Enterprise Application

- Created/configured the Contoso HR Portal enterprise application
- Reviewed application properties
- Configured application access settings
- Reviewed roles and administrators

### 4. Access Management

- Explored role assignments
- Configured access-related settings
- Demonstrated identity-based access control

### 5. Single Sign-On

- Configured and reviewed SSO settings
- Explored authentication-related configuration

### 6. Administration

- Reviewed Microsoft Entra roles and administrators
- Explored administrative units
- Reviewed delegated administration concepts

### 7. Monitoring

- Reviewed audit logs
- Explored Conditional Access monitoring
- Reviewed SCIM provisioning limitations
- Examined identity-related activity and reporting
